## Aim

To implement and study fundamental Artificial Intelligence algorithms and techniques through practical laboratory experiments.

## Experiments

1. **Lab 1:** Breadth-First Search (BFS), Depth-First Search (DFS), and Linear Regression.
2. **Lab 2:** Best-First Search, A* Search, AO* Search, and Hill Climbing.
3. **Lab 3:** Logistic Regression.
4. **Lab 4:** 8-Puzzle Problem, 8-Queens Problem, and Tic-Tac-Toe.
5. **Lab 5:** Minimax Algorithm for Game Playing.
6. **Lab 6:** Single-Layer Neural Network.
7. **Lab 7:** Forward Chaining and Backward Chaining.
8. **Lab 8:** Genetic Algorithm.
